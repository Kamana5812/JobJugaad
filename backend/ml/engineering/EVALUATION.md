# BTech placement model — measured public-data evaluation

Source: [Engineering Placements Prediction](https://www.kaggle.com/datasets/tejashvi14/engineering-placements-prediction), Tejashvi/Kaggle version 6, CC0. Publisher describes university engineering-placement records from 2013–2014; original collection and university identity are not independently audited. Imported labels are not generated by JobJugaad. See [source/checksum](../../data/engineering/source.json).

## Frozen procedure

Commit `e5d4169` records source, four input features, preprocessing and the fixed split/model settings before training. One 300-tree Random Forest with balanced training class weights; no test-set tuning, seed search, best-fold selection or holdout refit. Use CGPA through semester 6, engineering stream, completed internships and ever-backlog history. Age, gender and hostel residence are excluded by design; this does not prove fairness. Target is PlacedOrNot, never an input.

All identical four-field input profiles stay together. Take only the first fixed StratifiedGroupKFold split (5 folds, shuffle true, seed 42); fit the encoder only on training rows. Approximate 80/20 split: **2,374 training rows / 592 held-out rows**, containing **140 training / 41 held-out distinct profiles**, no group overlap. The full source has 2,966 rows but only 181 distinct modeled profiles, with 58 mixed-label profiles. Repeated records must not be treated as independent unique students. No oversampling is used.

Positive class: Placed (1). Measured on the 592 held-out records:

|---|---:|
| Correct classifications | 497 / 592 |
| Accuracy | 83.95% |
| Precision | 96.77% |
| Recall | 73.39% |
| F1 | 83.48% |
| Training-majority baseline accuracy | 55.24% |

Confusion matrix, rows actual / columns predicted:

| Actual outcome | Not Placed | Placed |
|---|---:|---:|
| Not Placed | 257 | 8 |
| Placed | 87 | 240 |

The model misses 87 of 327 placed records at its default classification decision. Do not use it to reject students. All predictions, both-class metrics, row split membership, dependency versions and hashes are preserved in [evaluation_report.json](evaluation_report.json). The artifact is the same pipeline trained on 2,374 rows, not all 2,966. These results are distinct from the MBA classifier and the synthetic matching/readiness/support checks.

## Application boundary

Separate optional BTech profile inputs; no MBA fields, gender, age or hostel inputs. The six supported streams are Civil, Computer Science, Electrical, Electronics And Communication, Information Technology and Mechanical. Source CGPA values are integers 5–9 and internships are 0–3. Inputs outside these ranges are saved unchanged but receive no model score; unknown fields are not imputed. Finer CGPA precision is not validated. Backlog history is not current active backlog count.

The API loads the trusted checksum-verified model once per process. Its uncalibrated score always includes a training-root baseline, four signed local tree-path contributions and a fixed explanation. Contributions reconcile to the saved forest output; these are descriptive model factors, not causes or calibrated probabilities. No effect on weighted readiness, matching, eligibility, support or offers. The old dataset and single grouped internal split do not establish current-cohort, external-college or production performance. No first-mover, fairness or guaranteed placement claim.

## Reproduce

From the repository root with existing pinned dependencies:

```powershell
backend/venv/Scripts/python.exe backend/ml/engineering/train_model.py
```

Runtime imports only inference code; training is manual. Do not change the predeclared procedure after viewing these test results without a new evaluation design. Never load uploaded joblib files.
