# Bundled pretrained model

Source: https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2

Revision: `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`.

The source repository distributes this model under Apache-2.0; see LICENSE.txt. The original quantized ONNX file `onnx/model_quint8_avx2.onnx` is included unmodified as `model.onnx`; the original tokenizer is included unmodified. Model weights were not trained or tuned by JobJugaad. SHA-256 checksums and pooling settings are in manifest.json and verified before loading. Reproduce the downloads with scripts/fetch-semantic-model.py. No private application data is included here.

Use and limitations are documented in docs/NLP-UPGRADES.md. This is optional descriptive evidence and does not replace the default weighted matching engine or establish validated placement accuracy.
